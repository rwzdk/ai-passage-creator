# AI Passage Creator 前端“沅水青山”视觉改造设计规格

## 1. 目标

在不改变现有核心业务流程的前提下，为完整前端建立统一的“沅水青山、诗意清冷、水墨淡染”视觉系统，提升页面层次、内容可读性、滚动场景变化和交互反馈。

改造范围覆盖全局布局、首页、登录注册、文章创作、作品列表与详情、个人资料、VIP 支付、后台管理和统计页面。每个页面完成后单独验证并创建 Git 提交，便于逐页回退。

## 2. 设计语言

### 2.1 情绪关键词

沅水、青山、渡口、远雾、薄光、旧纸、墨色、清晨、留白、安静流动。

### 2.2 颜色 Token

```css
--ink-deep: #203b38;
--mountain-green: #456f64;
--river-green: #8fb8a4;
--mist-white: #f3f7f3;
--paper-warm: #f7f5ee;
--ink-muted: #6f817a;
--accent-gold: #c7a878;
--line-soft: rgba(32, 59, 56, 0.12);
--glass-surface: rgba(247, 250, 246, 0.74);
--glass-surface-strong: rgba(247, 250, 246, 0.9);
```

现有品牌绿色保留为交互强调色，但降低大面积纯色占比；正文、表格和表单优先使用深墨色和暖白背景，保证对比度和可读性。

### 2.3 材质与组件

- 页面背景：低对比度自然场景或抽象水墨纹理。
- 内容面板：轻毛玻璃、细边框、柔和阴影；不使用过度透明导致文字难读的面板。
- 卡片：统一圆角和内边距，悬停时只做轻微上浮和边缘微光。
- 按钮：主按钮、次按钮、文字按钮、危险按钮使用统一高度、圆角和状态反馈。
- 图标：优先使用现有 Ant Design Icons，避免新增不必要的图标库。

## 3. 页面场景规划

| 页面 | 主场景 | 动态重点 |
| --- | --- | --- |
| 全局布局 | 浅雾纸面与青绿色导航 | 页面切换、导航激活、全局加载 |
| 首页 | 沅水清晨、远山和水面 | 首屏渐入、创作流程、数字统计、内容滚入 |
| 登录/注册 | 薄雾渡口和留白水面 | 表单分步反馈、错误提示、提交状态 |
| 文章创作 | 临水书桌、纸张和墨迹 | 步骤进度、正文流式显示、生成状态 |
| 作品列表/详情 | 沿江小路、旧书页和远山 | 列表错峰出现、正文分段展开、阅读进度 |
| 个人资料 | 清晨山谷和平静水面 | 场景锁定、统计数字、作品时间线、头像交互 |
| VIP 支付 | 夕照沅水与克制金色光线 | 权益卡片、价格切换、支付状态过渡 |
| 管理后台/统计 | 抽象山脉和水纹 | 图表逐步绘制、表格加载、筛选反馈 |

一个背景绑定一个完整场景或一组紧密内容；背景切换由场景进入视口的比例驱动，不由单个卡片触发。

## 4. 动画与滚动机制

### 4.1 全局规则

- 页面路由：淡入 + 轻微上移，使用 `Transition`，不做夸张缩放。
- 内容进入：使用 `IntersectionObserver`，按标题、摘要、卡片、数据块分层进入。
- 背景加载：先预加载当前场景背景，再显示内容；下一场景背景提前低优先级预加载。
- 背景切换：使用双层交叉淡化和轻微位移，避免上一个场景残留或闪烁。
- 数字动画：使用 `requestAnimationFrame` 从 0 递增到真实值，切换场景时不重复抖动。
- 图表动画：数据准备后再绘制，数据为空时显示明确空状态。
- 无障碍：遵循 `prefers-reduced-motion`，减少动画时保持内容顺序和可操作性。

### 4.2 通用动画组件

计划抽取以下组件，供所有页面复用：

```text
frontend/src/components/motion/PageTransition.vue
frontend/src/components/motion/ScrollReveal.vue
frontend/src/components/motion/CountUpNumber.vue
frontend/src/components/motion/LazySection.vue
frontend/src/components/motion/SceneBackground.vue
frontend/src/components/motion/AnimatedSkeleton.vue
frontend/src/components/motion/StaggerList.vue
```

组件只负责动画和状态，不持有业务请求；请求、数据转换和错误处理继续留在页面或 API 层。

## 5. 页面实现边界

- 保留现有路由、登录状态、文章接口、支付接口和个人资料接口。
- 优先复用现有 Ant Design Vue 组件和项目已有背景资源。
- 不在本次视觉改造中重写后端接口或数据库结构。
- 新增背景图时使用本地资源，并在提交前检查尺寸、压缩格式和加载表现。
- 动画不得阻塞首屏主要操作，按钮和表单必须在动画未完成时仍可用。
- 每个页面的提交只包含该页面及其必要的共享样式/组件变更，不提交无关用户改动。

## 6. 交付顺序与验收

每个阶段执行：

1. 修改页面和必要共享组件。
2. 运行类型检查、构建和页面级浏览器验证。
3. 检查正常、加载、空数据、错误、权限和减少动画状态。
4. 创建独立 Git 提交。

验收尺寸：375px、768px、1024px、1440px。

首个提交建立全局视觉 Token、布局、页面切换动画和导航状态；后续按页面逐个提交。

## 7. 背景图素材规则

背景图不放文字、Logo、水印和高对比主体；主体放在右侧或边缘，中央/左侧保留文案空间；整体低饱和、低对比、带自然雾气，避免面板叠加后内容不可读。
