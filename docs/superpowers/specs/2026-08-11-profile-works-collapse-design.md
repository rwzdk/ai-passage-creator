# 个人资料页作品收缩设计

## 范围

- 移除个人资料页顶部固定的绿色进度线 `.profile-progress`。
- “我的作品”中的每篇作品默认只显示标题及元信息，不显示正文。
- 点击作品标题切换正文展开/收起；刷新或重新进入页面后全部恢复收起。

## 实现

- 在 `UserProfilePage.vue` 中使用 `Set<string>` 保存当前展开作品的唯一键。
- 作品唯一键沿用列表渲染使用的 `taskId || id`，避免新增数据字段或接口变更。
- 标题按钮增加 `aria-expanded`，展开时显示向上箭头，收起时显示向下箭头。
- 仅在作品处于展开状态时渲染 Markdown 正文，减少默认页面内容和渲染量。

## 验证

- 前端类型检查/构建通过。
- 代码差异检查通过。
- 手工确认资料页不再显示顶部绿色进度线，作品标题可重复展开和收起。
